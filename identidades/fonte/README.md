# Anderflow Nexo — Display Regular

Fonte display autoral criada do zero para a identidade Anderflow.

## Arquivos
- `Anderflow-Nexo-Display-Regular.ttf` — arquivo TrueType para instalação e edição.
- `Anderflow-Nexo-Display-Regular.woff2` — arquivo web otimizado.

## Escopo
A família contém alfabeto latino básico, números, pontuação e caracteres usados em português, incluindo acentos e cedilha. O desenho é destinado principalmente a títulos, assinatura e peças de destaque.
