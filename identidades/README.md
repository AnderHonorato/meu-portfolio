# Identidades visuais

Esta pasta reúne os três sites individuais da apresentação de identidades visuais autorais de Anderson Honorato. O material foi criado para ser visto por clientes: cada página explica o contexto, a decisão de design, os formatos de aplicação e o próximo passo.

| Página | Direção | Arquivo |
|---|---|---|
| Índice | Apresentação geral e escolha de projeto | `identidades.html` |
| Anderflow | Estúdio de identidade e presença digital | `anderflow.html` |
| Seiva | Produto botânico e pequenos lotes | `seiva.html` |
| Fio Norte | Cultura, eventos e publicação | `fio-norte.html` |

A pasta `assets/` contém os mockups demonstrativos e o símbolo usado na navegação. A pasta `fonte/` contém `Anderflow-Wordmark-Regular.ttf`, um arquivo TTF autoral de wordmark desenhado para a identidade Anderflow. A família deve ser usada em títulos curtos, assinaturas e navegação; para textos longos, mantenha a família de leitura definida em `style.css`.

Os exemplos mostram formatos de uso como logo horizontal, símbolo, avatar, capa de proposta, rótulo, etiqueta, lacre, embalagem, cartaz, programa, ingresso, kit digital e guia de continuidade. Os arquivos são páginas HTML estáticas e funcionam no GitHub Pages sem dependência de servidor.
